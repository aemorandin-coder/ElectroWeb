# C-05 — Carrito
Estado: HECHO
Rama: claude/C-05 (hotfix: mergear y desplegar apenas esté revisada; no depende de C-01)

## Qué cambió
- **`contexts/CartContext.tsx`**
  - **B1:** el carrito se reconcilia con la BD **una vez por sesión de login**, no en cada montaje. La marca `cart-db-synced:<userId>` en `sessionStorage` evita repetirlo al recargar la pestaña. `localStorage['cart-owner']` guarda de quién es el carrito local:
    - misma cuenta (o carrito guardado antes de este cambio, sin dueño): gana la BD si tiene productos;
    - invitado (`guest`, se marca al tocar el carrito sin sesión): se suman cantidades, una sola vez, con tope de stock;
    - otra cuenta: se descarta el carrito local.
  - Solo se guarda en la BD después de reconciliar con éxito. Si `GET /api/cart` falla, ya no se pisa la BD con un carrito viejo.
  - Al cerrar sesión se borran las marcas, así el próximo login vuelve a reconciliar.
  - **B2:** `addItem` limita al stock también los productos nuevos. Si el stock es 0 no agrega nada.
  - **B3:** nuevo `totalItems` (unidades). `getTotalItems()` se mantiene por compatibilidad y devuelve lo mismo. `useCartSafe` incluye `totalItems: 0`.
  - `localStorage`/`sessionStorage` van dentro de try/catch (modo privado).
- **`components/CartIcon.tsx`** y **`components/public/MobileNavBar.tsx`**: los dos contadores usan `totalItems` y muestran `9+` a partir de 10. Antes la barra móvil contaba líneas.

## Cómo se verificó
- `npx tsc --noEmit` → 0 errores. `npm run build` → OK.
- `eslint`: 0 problemas nuevos. `CartContext.tsx` sigue con los 2 errores `set-state-in-effect` que ya tenía (carga desde localStorage y logout) y pierde 1 warning.
- **Laboratorio con el `CartProvider` real** (jsdom, `useSession` y `/api/cart` simulados; cada "recarga" desmonta y monta el provider con el mismo storage): **13/13 PASS**. Contra la versión de `main` el mismo laboratorio da 3/13 y reproduce el bug: **1 → 2 → 4 → 8 → 10**.
  - Logueado: agregar 1 unidad y recargar 5 veces → 1, 1, 1, 1, 1; la BD queda en 1 y solo se pide `/api/cart` una vez.
  - Carrito duplicado de antes del arreglo (sin dueño): 3 cargas → no cambia.
  - Invitado con 2 unidades (BD con 1) que inicia sesión, sin recargar y con redirect → 3, una sola vez, estable al recargar.
  - Suma con tope de stock (8 + 5, stock 10) → 10.
  - Producto nuevo con 7 unidades y stock 3 → 3. Stock 0 → no se agrega.
  - `totalItems` = unidades (5 con 2 líneas).
  - Pestaña nueva del mismo usuario → toma la BD. Cerrar sesión → carrito vacío y sin marcas. Otra cuenta → solo su carrito, nunca el de la cuenta anterior.
