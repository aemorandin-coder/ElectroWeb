# C-146 · "IVA incluido" con la base y el IVA, en vez de "Impuestos (Exento)"

Estado: HECHO (rama `claude/C-146`, sale de `main` con C-145; **sin cambio de base**). Queda una segunda parte: el precio sugerido desde el costo (abajo, "Pendiente").

Andrés lo marcó **crítico** el 30/09. Sus precios publicados ya llevan el IVA, y el carrito y el correo decían "Impuestos (Exento)", que no es cierto para lo que vende la tienda.

## Regla
- **El total no cambia.** La tienda nunca suma el IVA: dice cuánto del total es IVA y cuál es la base imponible.
- El IVA va sobre todo lo que cobra la tienda en la orden: productos menos descuentos, más embalaje o delivery. El flete con cobro a destino no entra: lo cobra la empresa de envíos.
- El porcentaje sale de **Configuración → Precios → IVA**. Sin porcentaje, no se muestra nada.
- Ejemplo: total $60,00 → "IVA incluido (16 %): $8,28 · Base imponible: $51,72".

## Dónde se ve
| Lugar | Qué muestra |
|---|---|
| Ficha del producto | "IVA incluido" bajo el precio |
| Carrito | La línea de IVA y base bajo el total. Fuera "Impuestos (Exento): $0,00" |
| Pago | La misma línea bajo el total, con el embalaje o el delivery ya dentro |
| Correo de compra | "Incluye IVA (16 %): 8.28 USD · Base imponible: 51.72 USD". Fuera "Impuestos (Exento)" |
| Recibo en Mis pedidos (y al imprimirlo) | La línea bajo el total |
| Panel → detalle de la orden | La línea bajo el total |
| Configuración → Precios | El interruptor pasa de "Cobrar IVA: se suma al total" a "Los precios incluyen IVA" |

## Cómo queda guardado
- Cada orden guarda en `taxUSD` el IVA que llevaba dentro al comprarla. Si el porcentaje cambia después, los pedidos viejos conservan el suyo.
- Las órdenes de antes tienen 0 y no muestran la línea.
- `lib/pricing.ts`: `ivaIncluido()` y `porcentajeIva()`. Se fue `STORE_CHARGES_TAX`. `calculateGroup` ya no suma el impuesto.
- `components/ui/IvaIncluido.tsx`: el mismo texto en el carrito, el pago, el recibo y el panel.
- Los ajustes públicos llevan `taxEnabled` y `taxPercent` (no son datos sensibles: van impresos en cada recibo).
