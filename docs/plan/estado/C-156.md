## El redondeo de C-96, en un comando
`docs/plan/scripts/redondeo-c96.sql`. Hace lo mismo que el SQL de `estado/C-96.md`, con una protección: solo redondea las cuentas cuya diferencia con el centavo es menor que una millonésima de dólar. Si alguna tuviera una diferencia real, no la toca y la cuenta aparte.

Probado en la tienda de ejemplo (`rev10_demo`):
| Caso | Resultado |
|---|---|
| Una cuenta con `9.999999999999999` y `0.000000000000001` | "con arrastre: 1", `UPDATE 1`, queda `10.00` y `0.00`, "después: 0" |
| Segunda corrida | "con arrastre: 0", no cambia nada |
| Una cuenta con `10.005` (diferencia real) | "diferencia real: 1"; el valor queda en `10.005` |
La tienda de ejemplo quedó como estaba.
