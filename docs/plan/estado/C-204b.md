# C-204b · Lo que no se envía, sin falsos positivos, y las hojas de una carpeta

Estado: HECHO

Pedido de Andrés del 12/11, con una captura de la Lista del proveedor: "El filtro me descarta ese producto, cuando claramente no es gasolina". Era la "Motobomba a gasolina 6,5 HP 2×2 Daewoo" (R023137), marcada como "No se envía por ZOOM ni MRW ("gasolina")".

En la misma captura había otro error de C-204: el "Modelo" de la fila decía "Daewoo GAEH50 (motobomba a gasolina 6,5 HP, entrada y salida…". Al soltar la carpeta "Fotos del fabricante" entera, la pantalla leyó como listas del proveedor los tres `.csv` de trabajo que hay adentro (`fuentes.csv`, `lista.csv` y `Sin foto todavia.csv`), y sus columnas "modelo_encontrado" y "grupo" se mezclaron con la lista.

## Qué cambió
**1. La regla de lo que no se envía (`lib/proveedores/no-se-envia.ts`)**
- **Después de "a", "para" o "P/", la palabra no cuenta:** dice con qué funciona o para qué sirve. Así se crean "Motobomba a gasolina", "Pistola para pintura", "Regulador para bombona", "Brocha para barniz" y "Lámpara a alcohol". "Gasolina blanca", "Pintura de aceite" y "Bombona de gas" siguen fuera.
- **Sin "satinado":** también es un acabado de cerradura ("níquel satinado", R010078 de los 70). La pintura satinada cae igual por "sati" (como la escribe su sistema), "pintura" o "esmalte".
- **"pega para pvc"**, además de "pega pvc".
- **Excepciones:** una línea con "+" deja pasar un producto: su código ("+R023137") o una palabra de su nombre ("+motobomba"). Una lista que solo trae excepciones vale la de siempre con ellas.
- **El botón "Sí se envía"** en cada fila marcada agrega su código como excepción. El editor de la lista la muestra ("1 excepción · sin guardar") y se guarda con "Guardar la lista" o al crear, como el resto de la lista.
- El servidor recibe el código de cada fila: la excepción vale también allí.

**2. Las hojas que vienen dentro de una carpeta no se leen (`_componentes/fotos.ts`)**
- De una carpeta, elegida o soltada, solo se toman las fotos. Una hoja (`.xls`, `.xlsx` o `.csv`) se lee solo si se eligió o se soltó suelta.
- Un aviso dice cuáles no se leyeron: "3 hojas que venían dentro de la carpeta no se leyeron (fuentes.csv, lista.csv…): de una carpeta solo se toman las fotos".
