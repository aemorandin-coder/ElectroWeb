# C-248 · Dos botones de Contabilidad con la regla del "!"

Estado: HECHO (rama `claude/C-248`; versión `1.0.0-rc.62`; sin cambio de base)

El 15/11 la sesión de C-245 dejó un pendiente para quien lleva Contabilidad: `AsistenteFactura.tsx:356` tiene un botón con `px-0` que aprieta el ícono. Es la regla que encontró C-245 (`PLAN.md` §1.8): en el CSS, `px-5`, `h-11` y `text-ink` del botón compartido van después de lo que se le suma, y lo que se suma gana solo con `!`.

## Qué cambió
- **"Quitar el renglón"** (Contabilidad → Nueva factura → "Una venta en la tienda" → Qué se vendió): `px-0` pasa a `px-0!`.
  - En la computadora, el botón vive en una columna de 44 px. Con los 20 px de relleno de cada lado, el tacho quedaba en 4 px.
  - Ahora se ve entero (16 px) y centrado.
- **"Copiar datos para facturar"** (el detalle de la orden → Facturación, de C-229): al copiar, el borde y la letra pasan al verde fuerte, como se pensó. Antes `border-line` y `text-ink` del botón le ganaban y solo cambiaban el ícono y el texto.
- **Revisé los demás botones compartidos de Contabilidad:** lo que se les suma es margen o ancho (`mt-3`, `w-full`, `shrink-0`), que no choca con el botón.
  - Queda `h-9` en "Facturar" de "Por facturar" (`PanelFacturas.tsx`, de C-242): el botón mide 44 px. Es la medida para tocar en el teléfono, así que no se cambia.
- **Módulos:** Contabilidad 1.2.2 y Órdenes y pagos 1.6.3.

## Verificación
- **`npx tsc --noEmit`, ESLint de los dos archivos, `npm run check:modulos`, `npm run check:marca` y `npm run build`:** pasan.
  - El build se hizo contra la base de prueba portátil (puerto 55439, esquema `c248_test`).
- **El CSS compilado** tiene `.px-0\!{padding-inline:0!important}`, y lo mismo con `border-color` y `color` del verde fuerte.
- **En Chrome (`playwright-core`, `next start`): 2 de 2.** El asistente con una venta de la tienda, hasta Qué se vendió con dos renglones.
  - A 1440 y a 360, el botón "Quitar el renglón 1" no tiene relleno y su ícono mide 16 px. Revisado en la captura.
- **"¡Copiado!"** se comprobó solo en el CSS compilado, sin abrir una orden en el navegador.
