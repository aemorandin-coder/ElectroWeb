Cada ruta de `app/api/customer/**` y las que usa Mi panel (`/api/orders`, `/api/orders/<id>/digital`, `/api/user/profile`, `/api/user/enrollments`, `/api/notifications`, `/api/legal/**`, `/api/reviews`) se probó sin sesión, con IDs de otro cliente y con datos manipulados.

- **Además:**
  - `app/api/customer/wishlist`: el producto tiene que ser un texto y la acción "add" o "remove" (con un objeto, "remove" vaciaba la lista propia);
  - `app/api/reviews?mine=1`: Mis reseñas pide solo las propias (una cuenta del equipo veía las de todos como suyas);
