# C-289 · Ajustes, acceso y herramientas claras: el plan y la skill

Estado: HECHO (el plan, la skill y dos decisiones; el código va de C-290 a C-294)

**El pedido (18/11):**
- **Los dos pasos:** la contadora no entendía "qué app es doble factor" ni qué hacer después, y pidió un dispositivo de confianza por 30 días.
- **Una regla para todo:** mensajes claros, íconos, poco texto, muy gráfico, con ejemplos como Authy, Google Authenticator o Microsoft, y cómo se bajan de la Play Store. "Esto debe ser una skill global para que todo el equipo de desarrollo sepa cómo debe crear herramientas."
- **La IA:** que no sea solo Claude, para poder cambiarla mañana por Gemini o Grok.
- **El login de los administradores,** también con dispositivo de confianza.
- **Ajustes:** un análisis de lo que se queda, por los campos anchísimos, los textos largos, los nombres ilógicos y lo repetido.
