## 3. Lo que estaba mal y se corrigió

### Rompía el build (los estados decían "tsc: 0 errores"; no se corrió)
1. `app/creator/page.tsx`: usaba `adminPrimaryButton` **sin importarlo** (2 usos).
2. `components/cursos/CourseDetailClient.tsx`: usaba `useBodyScrollLock` y `adminModalOverlay` **sin importarlos**.
   → `npx tsc --noEmit` daba 4 errores y `npm run build` fallaba. Imports agregados.

### Bugs
3. **`app/registro/page.tsx`:** el campo **Correo** pintaba el error del campo **Nombre** (`touchedFields.name && validationErrors.name`, copiado del bloque de arriba). Ahora usa `email`.
4. **Panel de creadores: "Algo salió mal"** en `/creator/dashboard` y `/creator/dashboard/cursos` (preexistente, no de R10). La API manda los `Decimal` de Prisma como texto y la página hacía `course.rating?.toFixed(1)` y sumaba strings en el promedio. Se convierten con `aNumero()` al recibirlos. Con un curso con calificación, las dos páginas quedaban inservibles.
5. **Todos los modales `fixed` de la tienda aparecían al final de la página** en vez de sobre la pantalla (preexistente, C-33 lo había parcheado solo para la barra móvil). `.page-transition-wrapper` (app/layout.tsx) animaba con `transform` y `animation-fill-mode: forwards`, así que conservaba un `transform` calculado y se convertía en el bloque contenedor de todo `position: fixed`. Se veía la capa oscura y el panel quedaba fuera de la vista si la página estaba desplazada. La animación ahora es solo de opacidad (`app/globals.css`), y se borró la regla muerta `.page-transition-wrapper.transitioning`.
   Comprobado a 390 px: el modal del portafolio de servicios, el del video de una lección y los de gift cards pasan de `rect y=-309/-769/-826` a `y=0` (pegados a la ventana).
6. **Login: redirección de vuelta rota y redirect abierto.** Seis páginas mandan `/login?redirect=/ruta` pero el login solo leía `callbackUrl`, así que el cliente terminaba en `/`. Además `callbackUrl.startsWith('/')` aceptaba `//sitio-externo.com`, que el navegador trata como URL absoluta. Ahora una función `rutaInternaSegura()` acepta `callbackUrl` **y** `redirect`, y rechaza `//`, `/\` y `/admin`.
